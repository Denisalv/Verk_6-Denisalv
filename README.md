# Verk_6-Denisalv
Ég er að búa til snjallan kassa sem opnast þegar rétt RFID-kort er skannað. Ég nota RC522 RFID-kortalesara sem er tengdur við ESP32. Þegar rétt kort er skannað sendir ESP32 merki til mótors sem opnar kassann. Kassinn getur einnig verið opnaður og lokaður í gegnum vefsíðu sem ég hef forritað í Python. Þannig er hægt að stjórna kassanum bæði með RFID-korti og í gegnum vefsíðuna.
