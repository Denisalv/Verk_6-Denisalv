# Verk_6-Denisalv
### Snjall kassi með RFID

Verkefnið mitt er að búa til snjallan kassa sem hægt er að opna og loka með RFID-korti eða í gegnum vefsíðu. Ég nota ESP32-stýritölvu og RC522 RFID-kortalesara til að lesa kort. Þegar rétt kort er skannað sendir ESP32 merki til mótors sem opnar kassann. Einnig hef ég búið til vefsíðu með Python þar sem hægt er að opna og loka kassanum með hnöppum. Markmiðið er að búa til öruggan og þægilegan kassa sem hægt er að stjórna á tvo mismunandi vegu.

### Hvað er eg að nota
1. **ESP32-S3** – Stýritölva sem stjórnar verkefninu.
2. **RC522 RFID-lesari** – Les RFID-kort til að opna kassann.
3. **RFID-kort** – Notað til að auðkenna notandann.
4. **Mótor** – Opnar og lokar kassanum.
5. **Kassi** – Sjálft hylkið sem geymir hlutina.
6. **Tengivírar** – Tengja RC522-lesarann við ESP32.
